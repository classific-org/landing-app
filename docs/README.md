# Classific Complete Design System Starter Kit

Includes the design-system guide, CSS tokens, homepage reference and crops, SVG wordmark concept, editable outline SVG icons, and editable SVG background patterns.

## Folder map
- `DESIGN_SYSTEM_GUIDE.md` — brand direction, colors, typography, spacing, components, imagery, accessibility, responsive rules, and production checklist.
- `tokens.css` — CSS variables and basic button/layout helpers.
- `assets/reference/` — generated homepage concept and visual crops.
- `assets/logos/` — SVG wordmark concept.
- `assets/icons/` — individual editable outline SVGs.
- `assets/patterns/` — editable dot grid, contour line, and geometric plane patterns.
- `manifest.json` — package inventory.

## Important
The homepage image and crops are references, not individual original layers or editable vector artwork. The logo is a starter concept, not trademark-cleared. Replace any sample projects, metrics, testimonials, or client marks with real approved information before launch.
